# 사업자·약관·개인정보 안내 작성 상태 (2026-11-09)

## 반영한 범위
- 운영 주체: 주식회사 다이버시티하우스, 대표자 이동수. 기존 공식 홈페이지 공개 정보와 사용자 확인을 근거로 표시.
- 정주환은 Pay 서비스 문의 담당자. 개인정보 보호책임자로 임의 선임하지 않음.
- 사업자 푸터, 영어 본문과 한국어 전문 이용약관·처리방침, 회원가입·업로드 전 정책 링크.
- 테스트·실제 거래 구분, 제출 전 자동 저장, 취소와 파일 삭제의 차이 명시.
- 이번 작업은 안내 문서 작성/노출. 약관 동의 수집·버전별 동의 기록 기능은 추가하지 않음.

## 실제 문서 접수·출시 전 운영자 확정 필요
1. 공개 고객센터 전화번호의 운영자 확인(현재 이메일만 게시), 통신판매업 신고 적용 여부와 실제 신고번호·사업자정보 확인 링크. 번호를 만들거나 면제라고 단정하지 않음.
2. 개인정보 보호책임자 정식 지정과 연락처. 서비스 담당자와 대표자는 역할이 다름.
3. 실제 설정/계약에 따른 수탁자 정식 명칭, 처리업무, 국가, 보유기간 및 국외이전 법적 근거와 고지.
4. 회원·미제출 초안·취소/반려 신청·연결 계약서·로그·백업 각각의 보존기간과 실제 삭제 절차/자동화.
   현재 초안/연결 계약서 자동 만료 없음. 취소는 삭제 아님.
5. 개인정보 수집의 법적 근거별 안내·동의 필요 여부 검토, 필수/선택 분리, 약관 버전·동의 시각을 서버에서 기록.
   기존 이용자에게 과거 동의를 소급해 생성하지 않음.
6. PG 계약 후 수수료·환불·차지백·송금/정산 책임과 서비스 약관 확정, 법률 검토.
7. 실제 운영 설정과 정책의 일치 확인. 이 안내 게시만으로 출시 요건이 충족된 것은 아님.
